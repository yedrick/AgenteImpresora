Como conectar la tuya, si necesita driver y donde bajarlo.

Como se conecta

El destino es lo que pones al dar de alta la impresora en el panel. Casi todas admiten varias conexiones; usa la que tengas cableada.

USB

Linux y macOS: se ve como un dispositivo.

device:///dev/usb/lp0

Windows: por el nombre de la cola, tal cual sale en Dispositivos e impresoras.

EPSON TM-T20 Receipt

Red (Ethernet o WiFi)

La via mas comoda: no necesita driver en ningun sistema. El puerto estandar es 9100.

tcp://192.168.1.50:9100

La IP la imprime la propia impresora en su pagina de prueba.

Puerto serie

Modelos antiguos, o adaptadores USB a serie.

com://COM3 (Windows) device:///dev/ttyUSB0 (Linux)

Bluetooth

Se empareja primero en el sistema operativo; queda como un puerto serie.

bt://COM5 (Windows) bt:///dev/rfcomm0 (Linux)

Driver: cuando hace falta

Red Nunca. El agente habla directo con la impresora.
Serie / Bluetooth Nunca.
USB Hace falta una cola. Para casi todas basta el Generic / Text Only que ya trae Windows. Una cola raw de CUPS hecha con lpadmin, o escribir directo a /dev/usb/lp0. Sin driver de nadie. Igual que Linux: cola raw de CUPS.

Ubuntu en cuatro ordenes

Comprobado con una Epson TM-T88V por USB en Ubuntu 64 bits. El driver de Epson para Linux existe, pero es opcional: el agente no lo usa.

lsusb | grep -i epson # ver que Ubuntu la detecta lpinfo -v # copiar la URI usb://... sudo lpadmin -p TM-T88V -E -v "usb://EPSON/TM-T88V?serial=XXXX" -m raw lpstat -p # debe decir "inactiva y activada"

Probar antes de meterla en el agente:

printf '\x1b@Prueba\n\n\n\n\x1d\x56\x00' | lp -d TM-T88V -o raw

Si sale papel, el destino en el agente es el nombre de la cola: TM-T88V

El dialogo de Impresoras de GNOME no encuentra estas impresoras USB. Hay que crear la cola por terminal, como arriba. No es un fallo tuyo.

Windows, por USB

No descargues nada todavia: el driver que ya trae Windows sirve para casi todas.

  1. Configuracion → Bluetooth y dispositivos → Impresoras y escaneres
  2. Agregar dispositivo → Agregar manualmente
  3. Agregar una impresora local → puerto USB001
  4. Fabricante Generic, impresora Generic / Text Only
  5. El nombre que le pongas es el destino en el agente

Solo los modelos marcados abajo como Driver obligatorio necesitan el del fabricante.

Baja los drivers de la pagina oficial. Los que aparecen en buscadores suelen traer sorpresas, y una caja es mala PC para averiguarlo.
