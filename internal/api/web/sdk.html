No necesita internet: el paquete va dentro del propio agente. Es la via para una caja que no sale a la red.

Descargar el paquete

Dejalo en la carpeta de tu proyecto y:

npm install ./collatech-sdk.tgz

O directo desde este agente, si tu PC lo alcanza:

...

Si la PC tiene internet.

npm install collatech-sdk

Tambien con yarn add collatech-sdk o pnpm add collatech-sdk.

Si tu aplicacion corre en otra PC

  • El agente tiene que escuchar en la red: allow_remote: true en su configuracion.
  • Hay que mandarle el token de arriba.
  • El origen de tu aplicacion debe estar en allowed_cors, por ejemplo http://localhost:4200 si usas Angular en desarrollo.

La pagina de Diagnostico comprueba estas tres cosas y dice cual falla.
